1. Raw Image Transfer Commands (UpImage / DownImage)

    Commands: 0x0A (UpImage) and 0x0B (DownImage)

    What's lacking: Real AS608/R30x sensors allow the master board to download the actual raw graphical image buffer of the fingerprint (e.g., for streaming a live fingerprint preview to an OLED screen or PC).

    Current state: The simulator only deals with 3-bit synthetic switch codes, character templates (UPCHAR/DOWNCHAR), and 512-byte mock templates. Raw image streaming is completely absent.

2. Dynamic Baud Rate Configuration (SetBaudRate)

    Command: 0x0E (SetBaudRate)

    What's lacking: The Adafruit_Fingerprint library has functions to change the sensor's operating baud rate programmatically over UART.

    Current state: The baud rate is hardcoded on the ESP32 side via SENSOR_BAUD = 57600 in the user config. Any attempt by the master to change it dynamically will fail.

3. Dynamic Device Address Changing (SetChipAddr)

    Command: 0x15 (SetChipAddr)

    What's lacking: Real sensors allow you to change their hardware communication address from the default 0xFFFFFFFF so multiple sensors can share the same UART bus.

    Current state: DEVICE_ADDRESS is locked to 0xFFFFFFFF globally in the firmware.

4. Hardware Random Number Generator (ReadRandomCode)

    Command: 0x14 (ReadRandomCode)

    What's lacking: The sensor library can request a true random 32-bit integer generated by the fingerprint module's internal hardware.

    Current state: Not implemented. If called, it returns an unhandled packet error.

5. Flash Notepad / User Data Storage (WriteNotepad / ReadNotepad)

    Commands: 0x18 (WriteNotepad) and 0x19 (ReadNotepad)

    What's lacking: AS608 modules usually include a small non-volatile "notepad" flash page where developers can store arbitrary configuration bytes or user metadata strings (e.g., device status or configuration flags).

    Current state: Completely unimplemented; the fake sensor database only manages template slots (templateCode[]), not general-purpose data blocks.
